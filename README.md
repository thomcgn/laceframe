# Laceframe

**AI-assisted pixel-art production studio** — *From imagination to pixels.*

Laceframe is a planned cross-platform desktop application for generating, refining, managing and exporting consistent game art.

## Direction

- Electron + React + TypeScript + Vite
- Windows, Linux and macOS
- Prompt and image preview, with optional supported generation providers
- Character Master Lock and configurable expression families
- Sprite Strict, Portrait Artistic and Environment Artistic production profiles
- Non-destructive pixel cleanup, alignment, review and export

> Status: early architecture/design. Features listed are planned, not implemented.

## Architecture

See the documentation proposed in feature branches and pull requests. The first major design concerns versioned character masters, editable emotion presets and safe approval of expression variants.

## Notes

Image-generation access via ChatGPT sign-in and plan sharing depends on the official integration's actual eligibility and supported capabilities; neither ordinary Plus login nor a ChatGPT session is a general-purpose image API. No credentials, browser cookies or private image assets belong in this repository.
